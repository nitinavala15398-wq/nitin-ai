STARTER PREVIEW
₹0 budget: start with free tools

We’ll build the first version using free software and free hosting options where available. No paid subscriptions or purchases are needed to create this starter prototype. A live AI connection, custom domain, SMS/WhatsApp messaging or higher usage may require payment later, so we’ll keep those optional and check free limits before enabling anything.

📱 Android support is part of the plan

NITIN AI will be designed as a mobile-friendly website first, then prepared as an installable Progressive Web App (PWA) so Android users can add it to their home screen without paying for a Play Store listing. Installation will be enabled after the site is hosted securely and its app manifest and offline setup are added.
